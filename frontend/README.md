# Route Autopsy

Investigate vehicle-aware routes, test how sensitive a recommendation is to its evidence, and review road photos. Backend: see BACKEND_INTEGRATION.md.

## Development

Requires Node.js 20+ (or Bun).

```sh
npm install
npm run dev
```

Copy `.env.example` to `.env` and adjust values for your backend.

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm run test` – run tests
- `npm run lint` – lint

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

See `BACKEND_INTEGRATION.md` for backend wiring details.
